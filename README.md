# ✈️ Airline Passenger Satisfaction Prediction

## 📌 Project Overview
The **Airline Passenger Satisfaction Prediction** project is a Machine Learning-based system designed to predict whether an airline passenger is satisfied or dissatisfied based on various travel experiences and service-related factors.

This project helps airlines understand customer behavior and improve overall passenger experience by analyzing important features such as seat comfort, inflight services, online boarding, cleanliness, delays, food quality, and more.

The project includes:
- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Preprocessing
- 🤖 Machine Learning Model Training
- 📈 Model Evaluation
- 🌐 Flask Web Application Deployment

## 🔹 Step 1: Clone Repository

```bash
git clone https://github.com/sakshu3606/Airline-Passenger-Satisfaction-Prediction.git
```

---


## 🔹 Step 3: Install Required Libraries

